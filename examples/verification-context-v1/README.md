# Synthetic context structure only

`synthetic-linux.json` is an inert schema example based on the existing synthetic
Linux fixture. It is not an approved context, complete catalog, root approval,
signature proof or runnable release verification input. It retains synthetic
hashes and an illustrative macOS consumer validator pin; a Linux release can be
consumed on any supported native host with that host's independently approved
compiled validator identity. Review times are frozen fixture values.

Runtime semantic tests build their own test-only complete authority directory and
current short-lived reviews. Real adopters must independently resolve and approve
exact config/locks/catalog/policy/run/source/signers and review records. Never
copy this fixture or a download-provided context into a production approval.
