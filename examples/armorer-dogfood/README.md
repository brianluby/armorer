# Fit the armor to its maker

This is an inspection-intent example for Armorer's own CLI on three native
targets. Copy it only into an isolated exported Armorer checkout. This directory
has no Cargo workspace and cannot be inspected as a standalone project.

The [dogfooding guide](../../docs/dogfooding.md) gives the read-only exercise and
remaining hosted/signing/publication gates. This config supplies no dependency
license allowlist, signing secret, approved trust policy or release receipt.

Inspect the maker's work. Earn every later claim. **This is the way.**
